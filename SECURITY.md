# Security policy

Please report vulnerabilities privately to **security@askhooman.com**, not in public issues or pull requests.

Include what you found, how to reproduce it, and the impact you expect. We will acknowledge the report, keep you informed while we fix it, and credit you in the release notes if you wish.

In scope: this server, both the hosted mode (OAuth authorization server, MCP endpoint, app API, webhooks, Drive access) and the single-tenant bridge, and the official instance at `https://askhooman.com` (also served at its former address `https://qtracker.allover.art`). Please test only against your own accounts and data, don't degrade the service for others, and don't access other users' data.

Only the latest version on `main` receives security fixes.
